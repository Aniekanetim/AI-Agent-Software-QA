# Observed decisions and unresolved rationale

This agent-maintained area records statements found in available sources, inferred explanations, discrepancies and questions about decisions. Use the [knowledge-entry contract](../README.md); identify sources, roles, dates, revisions, observation versus inference, evidence, review state and refresh conditions.

An observed exception does not prove who decided it or why. Link any actual owner-confirmed decision in the [human decision baseline](../../../Project%20Context/decisions/README.md). Propose clarifications on the originating discovery request or QA ticket; do not publish an inferred rationale as an approved decision or automatically promote it into the human baseline.

No project decision knowledge is configured in this package.
